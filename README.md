# STM32F103 双通道 PWM 多模式呼吸灯控制器

本项目基于 **STM32F103C8T6**（标准外设库 SPL），利用通用定时器 **TIM2** 的 Channel 1 与 Channel 2 生成双通道硬件 PWM，通过独立按键状态机实现双路 LED 的多模式动态切换。

---

## 硬件配置与引脚接线

* **MCU**: STM32F103C8T6 (主频 72MHz)
* **驱动架构**: STM32 标准固件库 (StdPeriph Driver)
* **接线定义**:

| 外设模块 | 引脚 | 说明 |
| :--- | :--- | :--- |
| **LED 1** | `PA0` | TIM2_CH1，灌电流接法（低电平点亮） |
| **LED 2** | `PA1` | TIM2_CH2，灌电流接法（低电平点亮） |
| **Key 1 (模式切换)** | 按键引脚1 | 按键输入，切换运行模式 |
| **Key 2 (关机/复位)** | 按键引脚2 | 复位所有参数并熄灭 LED |

---

## 控制模式说明

系统运行基于枚举状态机，通过 **Key 1** 可以在各工作模式间单向循环切换，**Key 2** 随时一键关机并重置呼吸占空比：

| 模式编号 | 模式名称 | 运行效果 |
| :---: | :--- | :--- |
| **0** | `MODE_ALL_OFF` | 双灯全灭（待机状态，Key2 触发） |
| **1** | `MODE_ALL_ON` | 双灯全亮（恒定 100% 占空比） |
| **2** | `MODE_ALTERNATE_BLINK` | 双灯交替闪烁（爆闪警灯效果） |
| **3** | `MODE_SYNC_BREATH` | 双灯同相呼吸（亮度同步渐变） |
| **4** | `MODE_ASYNC_BREATH` | 双灯反相呼吸（一明一暗交替渐变） |

---

## 快速上手

1. 使用 **Keil uVision5** 打开工程文件。
2. 选择下载器（ST-Link 或 DAP-Link），编译并烧录至核心板。
3. 按下按键 1 观察 LED 模式轮转，按键 2 关闭并复位。
